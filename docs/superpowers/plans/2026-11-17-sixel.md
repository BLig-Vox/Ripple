# Chafa image support implementation plan

Goal: render Chafa bitmap output in Ripple and publish the patch.
Spec: ../specs/2026-11-17-sixel-design.md

1. Add a bounded Sixel decoder and image placement types in terminal/graphics.rs.
2. Integrate DCS handling, Sixel capability/geometry queries, scrolling, erases,
   alternate-screen isolation and eviction in TerminalGrid.
3. Cache GPU textures only for visible retained images; report actual cell/PTY
   pixel geometry from the existing measured terminal layout.
4. Build under the 2 GB cgroup cap, inspect native Chafa output and clear/scroll
   behavior, obtain read-only review and address findings.
5. Document supported format and limits, bump the patch version, install on Bot
   Screen, and publish crates.io/GitHub releases with matching artifacts.
