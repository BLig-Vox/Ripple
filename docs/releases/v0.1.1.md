# Ripple v0.1.1

Fixes image-only clipboard paste with Ctrl+Shift+V.

- Save clipboard images as private temporary PNGs and paste their paths, so local
  applications such as Codex CLI can attach screenshots.
- Keep ordinary text paste working when an X11 clipboard owner rejects an image
  request with an unexpected-type error.
- Clear stale clipboard errors after a successful paste.
- Retain images for the window lifetime, with limits of 32 files / 64 MiB of PNGs
  and 16 megapixels per image. Remove them on normal window close.

## Upgrade with Cargo

```sh
cargo install vox-ripple --version 0.1.1 --locked
```

Requires Rust 1.95 or newer and Linux graphics dependencies. After upgrading,
close and reopen Ripple. Ctrl+Shift+V pastes screenshot paths; Ctrl+V remains
available to the application running inside the terminal.

Desktop verification covered image-only PNG and text clipboard owners in the
Ubuntu Bot Screen's X11 session. Native Wayland and remote image attachment have
not been verified. This release retains the terminal prototype's VT limitations.
