# Bundled terminal font

JetBrainsMono Nerd Font Mono Regular, from Nerd Fonts v3.4.0:
https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/JetBrainsMono/Ligatures/Regular/JetBrainsMonoNerdFontMono-Regular.ttf

The font is embedded in Ripple so terminal symbols do not depend on desktop font installation. System fonts remain available as fallbacks. See OFL.txt and NERD-FONTS-LICENSE for the font and patching project licenses.
